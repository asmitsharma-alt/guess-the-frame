# Project Operating Rules

## Automatic Git Commit
After completing any prompt task that creates, modifies, or deletes files in this repository:
1. Verify `git status --short`.
2. Stage all modifications, new files, and deletions (`git add -A`).
3. Create a clean conventional commit (`git commit -m "type(scope): message"`).
4. Push to remote `origin main` (`git push origin main`).
5. Include the commit status and hash in the final response.
